MediaTek U-Boot System Recovery Mode

Erase Partition

WARNING: Erasing a partition will permanently destroy all data in that region.
This action CANNOT be undone! Make sure you know exactly what you are doing.

1. Erase NVRAM (0x000e0000, size 0x100000)

Resets all settings / environment variables to factory defaults.
MAC / calibration data in Factory partition are preserved.
Command: nmbm nmbm0 erase 0x000e0000 0x00100000

2. Erase Factory (0x001e0000, size 0x100000)

DANGEROUS: This partition contains MAC address, RF calibration data,
serial number, PIN code, country code, etc. Erasing it may cause
permanent loss of WiFi capability if no backup exists.
Command: nmbm nmbm0 erase 0x001e0000 0x00100000

3. Erase Factory2 (0x002e0000, size 0x100000)

DANGEROUS: This is the backup copy of the Factory partition.
If both Factory and Factory2 are erased, device will lose boot-time
calibration recovery and fall into invalid EEPROM state.
Command: nmbm nmbm0 erase 0x002e0000 0x00100000

4. Erase All Three Partitions

EXTREME DANGER: This will erase NVRAM + Factory + Factory2 simultaneously.
Only use this if you intend to fully re-provision the device afterwards.
Without restoring Factory data, WiFi will never work again.
